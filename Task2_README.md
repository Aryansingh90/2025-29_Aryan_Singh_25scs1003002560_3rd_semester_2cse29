# Task 02 - Guessing Game

A Python guessing game that generates a random number between 1 and 100.

## Features
- Generates a random number.
- Takes guesses from the user.
- Gives "too high" or "too low" feedback.
- Continues until the correct number is guessed.
- Displays the number of attempts.

## Run

```bash
python Task2_main.py
```
