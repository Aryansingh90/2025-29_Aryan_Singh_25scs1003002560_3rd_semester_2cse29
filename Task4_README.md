# Task 04 - Sudoku Solver

A Python Sudoku solver that uses a backtracking algorithm to fill the missing numbers in a 9x9 Sudoku puzzle.

## Features

- Uses `0` for empty cells.
- Checks rows, columns, and 3x3 boxes.
- Uses backtracking to find a valid solution.
- Displays the original and solved Sudoku grid.

## Run

```bash
python Task4_main.py
```

You can replace the numbers in the `grid` variable with another valid Sudoku puzzle.
