# Task 03 - Simple Contact Management System

A Python contact management program for storing and managing names, phone numbers, and email addresses.

## Features

- Add a new contact.
- View all saved contacts.
- Delete a contact.
- Store contacts persistently in a `contacts.json` file.

## Run

```bash
python Task3_main.py
```

The `contacts.json` file is created automatically when the first contact is saved.
