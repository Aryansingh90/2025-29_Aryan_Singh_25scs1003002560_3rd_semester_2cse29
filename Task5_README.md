# Task 05 - Web Scraping

A Python web-scraping program that extracts product information such as names, prices, and ratings from an e-commerce demo website and stores the results in a CSV file.

## Website

This project uses the publicly available demo website:

`https://books.toscrape.com/`

## Extracted Data

- Product/book name
- Price
- Rating

## Requirements

Install the required libraries:

```bash
pip install requests beautifulsoup4
```

## Run

```bash
python Task5_main.py
```

The scraped data is saved as:

```text
products.csv
```

## Note

This project is intended for learning and uses the Books to Scrape demo website.
